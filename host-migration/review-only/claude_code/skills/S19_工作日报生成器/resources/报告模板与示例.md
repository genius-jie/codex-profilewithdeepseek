# S19 日报报告模板与合格/不合格条目示例

> 由 S19 SKILL.md 外置。日报正文模板与条目质量示例。

## 7. 报告模板

日报 - YYYY-MM-DD

1. 【项目名称】
   - [完成/验证/排查了什么 + 具体对象/现象 + 结果价值/影响，避免短清单]
   - [如为 Jira/测试缺陷，写清实际现象、预期结果/影响、责任人和优先级]

待处理事项：
- [明确的阻塞点或次日跟进项]

### 合格条目示例
- 完成涛哥交代的小红书“快穿乙女”竞品分析，梳理高赞原因和热度来源，为后续内容策略判断提供参考。
- 验证记忆功能发现 APP 已解锁但问个人偏好仍提示未解锁，按“吴清华-P0”补齐现象和影响后流转 Jira。

### 不合格条目示例
- 完成小红书爬虫。
- 修复日报任务。
- APP 测试发现问题。
