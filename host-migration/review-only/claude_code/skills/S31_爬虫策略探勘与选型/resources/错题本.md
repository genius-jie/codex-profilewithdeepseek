## 📌 错题 #1：梅花网 React SPA 的 DOM 链接误读
- **日期**：2026-04-15
- **目标站点**：`https://www.meihua.info/`（基于 Next.js + MobX 的 SSR/SPA 融合架构）

### 1. 症状
在梅花网视频广告列表页 (`/shots!0!0!34!0!0`) 中：
- 页面渲染了 12+ 个视频卡片（含播放按钮和缩略图）。
- 但通过 `document.querySelectorAll('a[href*="/article/"]')` 或 `a[href*="/shot/"]` 只能提取到 **1 个** 无关链接。
- 用 Playwright 的 `page.click("img >> nth=2")` 点击卡片图片后，页面 URL 不变，无导航发生。

### 2. 病因
梅花网底层是 **Next.js + React Router + MobX** 架构：
- 所有视频卡片的跳转绑定在 React 虚拟 DOM 的 `onClick` 事件处理器上，而不是传统的 `<a href="...">` 标签。
- 标准的 HTML `<a>` 标签只有页头导航栏的几个固定链接。
- 卡片数据完全存储在 `window.__NEXT_DATA__.props.initialMobxState.shotsStore.shotsData.list` 这个 JSON 状态块中。
- 而且卡片的详情页 URL 路由是 `/shots/{compositionId}` 而不是 `/article/{id}`，直接搜 `article` 永远找不到。

### 3. 解除命令/方案
**彻底放弃 DOM 标签解析！** 改用 SSR 底层数据劫持法（方案 A1）：
```python
# 直接从 __NEXT_DATA__ 中提取完整的结构化数据
shots_data = await page.evaluate("""() => {
    let data = window.__NEXT_DATA__;
    return data.props.initialMobxState.shotsStore.shotsData.list;
}""")
# 每个 shot 对象包含: compositionId, title, brandName, cover, formName
# 详情页 URL = f"https://www.meihua.info/shots/{compositionId}"
```

## 📌 错题 #2：梅花网弹窗遮挡 (popupModal + mask-layer)
- **日期**：2026-04-15

### 1. 症状
Playwright headless 模式进入梅花网任何页面后，所有后续的 `page.click()` 操作超时失败。页面看起来正常但任何交互都被阻断。

### 2. 病因
梅花网首次访问会弹出一个全屏推广弹窗（`id="popupModal"`）+ 半透明遮罩层（`class="mask-layer"`），它们的 `z-index` 极高，覆盖在所有页面元素之上，导致 Playwright 无法触达底层任何可点击元素。

### 3. 解除命令/方案
在每次页面加载完成后，立即注入 JS 删除：
```javascript
await page.evaluate(() => {
    let m = document.getElementById('popupModal');
    if(m) m.remove();
    document.querySelectorAll('.mask-layer').forEach(e => e.remove());
});
```

## 📌 错题 #3：梅花网视频底层并非 iframe 加密——是原生 <video> 自托管
- **日期**：2026-04-15

### 1. 症状
预期梅花网视频和 SocialBeta 一样，走腾讯视频 iframe 嵌套加密流，需要 Playwright 物理盲截。但实际进入详情页后发现完全不同。

### 2. 病因
梅花网的视频使用 **video-react** 组件库的原生 `<video>` 标签 + `<source>` 直连自托管文件。文件存放在 `resource.meihua.info` CDN 上，URL 格式如：
```
https://resource.meihua.info/2SxYJ5jka40dYgykSYASyV3Rrik=/lgXdnzToywsUxqFeA5p66xNyUx6K
```
完整的视频元数据（分辨率、时长、文件名）也嵌在 `__NEXT_DATA__` 的 `shotsStore.detail.files` 数组中。

### 3. 解除命令/方案
**梅花网应归类为"直连抽帧"型（同数英网），而非"盲截"型（同 SocialBeta）！**
从 `files` 数组中筛选 `type === 3` 的条目即为视频文件，`wmUrl` 字段是可直下载的 CDN 链接。

## 📌 错题 #4：接口抓包法才是梅花网的最优路径
- **日期**：2026-04-15

### 1. 症状
花费了 V6-V10 共 5 个探针迭代版本、大量的 Playwright 刺探代码，才通过 `__NEXT_DATA__` 曲线拿到了数据。但其实梅花网有一个完全公开的 REST API 可以一个 POST 请求搞定一切。

### 2. 病因
前端 SPA 的底层数据来源就是后端 API。通过浏览器 F12 Network 面板过滤 Fetch/XHR，可以直接捕获到：
```
POST https://rest.meihua.info/composition/compositions
Content-Type: application/x-www-form-urlencoded
Body: client=9abeb059e15f90f74baf6ca6fca19a07&terms={"term":{"type":2,"formCodes":["34"]},"recommended":true,"page":1,"limit":45}
```
返回值是一个干净的 JSON 数组，每个对象包含 `id`, `title`, `brandName`, `cover`, `formId` 等完整字段。

### 3. 解除命令/方案
**方案 A（接口抓包法）是梅花网的终极最优路径：**
```python
import requests, json
resp = requests.post("https://rest.meihua.info/composition/compositions", 
    headers={"origin": "https://www.meihua.info", "referer": "https://www.meihua.info/"},
    data={"client": "9abeb059e15f90f74baf6ca6fca19a07", 
          "terms": json.dumps({"term":{"type":2,"formCodes":["34"]},"recommended":True,"page":1,"limit":45})})
works = resp.json().get('data', [])
# 每个 work 包含 id, title 等完整信息
# 详情页: https://www.meihua.info/shots/{id}
```
零 Playwright，零 DOM 解析，零弹窗干扰。一个 `requests.post` 搞定全场。

## 🧭 全局教训提炼

| 教训 | 心智模型修正 |
|:---|:---|
| 现代网页 ≠ 报纸 | 它们是前后端分离的应用程序，数据在 API 或 SSR JSON 里，不在 HTML 标签里 |
| Playwright 太重 | Playwright 确实能解决问题，但 99% 的情况用 API/JSON 方案更快且内存占用更小 |
| SPA 路由可能导致误判 | React Router 的"点击分类标签"不会触发真正的页面导航，URL 变了但异步数据可能没刷新 |
| `__NEXT_DATA__` 是 SSR 数据源 | Next.js 会把服务端渲染的初始数据写在 HTML 源码里，这是比 API 更底层的直给数据 |
| 永远优先 F12 抓包 | 探勘的第一步必须是打开 Network 面板找 API 数据，而不是直接写 Playwright 脚本 |

## 📌 错题 #5：Agent 面向表面标签的“偷懒型致幻”与硬证据法则的确立
- **日期**：2026-04-15
- **目标站点**：`https://socialbeta.com/`

### 1. 症状
Agent 利用 `requests` 闭眼抓取文章源码时，仅仅通过正则和 BeautifulSoup 扫描到了 `<iframe src="https://v.qq.com/...">`，就当场自信宣布：“SocialBeta 的底层没有加密，它是个传统 PHP 站，完全可以抛弃 Playwright 盲截（方案 B），降级到方案 A1！”
结果在被人类指挥官强硬诘问并要求物理验证后，才发现在截图里视频确实存在，但 Agent 根本没有深挖：**拿到了腾讯的 iframe 链接，拿得到里面的 MP4 吗？**

### 2. 病因
这是大模型极其典型的**“偷懒型合理化致幻”**：
1. **停止在虚假的胜利点**：看到 `iframe` 字符串就以为到了终点。但腾讯视频是重度 DRM 加密与 M3U8 切片的，单独的一个 `v.qq.com` 的 iframe 地址，在没有跑通 `yt-dlp` 下载测试时，对业务下游来说等同于废纸。
2. **缺乏“躬身入局”的沙箱打穿验证**：不入虎穴焉得虎子。没有真正去测试“这个方案能不能拿到最终目标文件”，就凭静态特征越权去改写了架构标准。

### 3. 解除命令/方案
1. **确立硬证据铁律**：在 S31 爬虫兵谱开头强制写入【M12 式防偷懒铁律】。探勘不仅要找到入口，必须提供**物理文件/直链**或**截屏视频证明**作为“硬证据（Hard Evidence）”。无法走到最后一步的探勘，一律作废！
2. **SocialBeta 方案最终收拢（经 yt-dlp 硬证据验证后翻案）**：
   - 第一步：`requests.get` 拿到 HTML 源码，BeautifulSoup 提取 `<iframe src="v.qq.com/txp/iframe/player.html?vid=XXX">`。
   - 第二步：从 iframe URL 提取 `vid`，拼成 `https://v.qq.com/x/page/{vid}.html`。
   - 第三步：`yt-dlp` 打穿腾讯 DRM，拿到 `.mp4` CDN 直链。
   - **硬证据**：`python -m yt_dlp --simulate --print "%(url)s" "https://v.qq.com/x/page/m3198nnaemb.html"` → 返回 `apd-vlive.apdcdn.tc.qq.com/.../f632.mp4` 直链，exit 0。
   - **最终定界**：SocialBeta 从「🔴 方案 B」**提权至「🟢 方案 A1 + yt-dlp」**。全程无需浏览器。

- `opencli doctor` 显示 daemon 已运行，但 `Extension: not connected` 或 Connectivity 失败。

## 📌 错题 #7：人工放行页打开后立即消失
- **日期**：2026-07-15
- **目标场景**：TopHub 龙虾 worker / OpenCLI Browser session / human-clearance 页签

### 1. 症状
- 真人 Chrome Profile 2 一直开着，OpenCLI 扩展已启用，`opencli profile list` 和 `opencli doctor` 都通过。
- worker 打开登录或人工放行页后，页面很快消失；普通 OpenCLI 采集命令仍可能成功。
- 直接执行 worker 生成的命令会报 `error: unknown option '--window'`，随后代码走 `cmd /c start` 兜底。

### 2. 病因
worker 把 OpenCLI 全局窗口参数放在了子命令后面：

```text
opencli browser <session> open <url> --window foreground
```

OpenCLI 要求 `--window` 放在 `open` 前。错误命令没有建立可复用的命名 session，普通浏览器兜底页也不受 human-clearance 保留契约保护，所以表现成“闪开闪关”。原来的页签治理目标没有错：普通采集页可以在任务结束后释放，人工放行页必须保留到用户处理完成。

### 3. 解除命令/方案
worker 必须按下面的顺序调用：

```text
opencli browser <session> --window foreground open <url>
```

验证时复用同一个 session，等待后再次读取状态：

```powershell
opencli browser human-clearance-retention-probe --window foreground open https://www.reddit.com/r/lovot/
Start-Sleep -Seconds 12
opencli browser human-clearance-retention-probe state
```

若第二条仍返回同一 URL 和页面状态，说明页签被命名 session 持有。不要为了修这个问题删除全局自动页签清理；只需要保证 `human-clearance-*` session 不走普通采集页关闭路径。

项目回归用例：`apps/web/tests-node/data-source-control-plane.test.mjs` 的 `Lobster worker keeps human-clearance tabs in a named foreground session`。
